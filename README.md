# Net Tester (Android)

Port Android de NetTester.exe.

## Compiler l'APK
**Option A - Android Studio** : File > Open (dossier NetTesterAndroid), attendre la synchro Gradle,
puis Build > Build Bundle(s)/APK(s) > Build APK(s).
APK : app/build/outputs/apk/debug/app-debug.apk

**Option B - sans rien installer (GitHub)** : creer un depot, y pousser ce dossier,
onglet Actions > "Build APK" > telecharger l'artefact NetTester-apk.
